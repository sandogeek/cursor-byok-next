# 界面语言（i18n）

本应用的多语言用 NSH 自带的 `nsh/i18n`，不引入第三方库。文案在 `locales/`，界面只调 `t()`。

## 结构

```
apps/desktop/
├── nsh.json                     # "locales": ["zh-CN", "en-US"]：Intl 数字/日期数据 + 打包时的 CFBundleLocalizations
├── locales/
│   ├── zh-CN.yml                # 文案源；key 描述意图（takeover.ca.missing.title），不写中文原句
│   └── en-US.yml                # 同一组 key 的英文；缺 key 时按 zh-CN → zh → en 回退
├── App.tsx                      # 启动时 restoreLocale() 再 mount，避免首帧闪一下系统语言
└── src/
    ├── screens/
    │   ├── Cursor.tsx           # 只用 t()；只管侧栏导航与页面切换
    │   ├── Calls.tsx            # 调用列表与清理确认
    │   ├── CallDetails.tsx      # 调用字段、请求 JSON、响应流
    │   ├── Plugins.tsx          # 同上；插件自带的文案走 localized()
    │   └── Language.tsx         # 语言条目、当前选择、持久化（nsh 的 Storage）；入口在系统设置页
    └── ui/
        ├── Button.tsx           # "处理中…" 走 t("common.loading")
        ├── Dialog.tsx           # 默认取消按钮走 t("common.cancel")
        └── localized.ts         # 运行时解析插件的 locale map
```

## 必须保持的行为

1. **默认跟随系统。** 用户没选过语言时不调 `setLocale`，由 `nsh/i18n` 按 `localeSettings().languages` 挑第一个有翻译的语言。
2. **选择要持久化。** `Storage` 键 `cursor-byok-next:locale`；选“跟随系统”时删除该键，而不是写入一个特殊值。
3. **切换立即生效。** `setLocale` 后所有 `t()` 绑定自动重绘；文案不要先算好放进常量。
4. **插件文案不进 `locales/`。** 插件返回 `{ "en-US": …, "zh-CN": … }`，由 `localized()` 按当前语言解析。Rust 边界（`LocalizedText`）保留原始 map，不再压成单一字符串。
5. **Rust 侧文案只写 key。** `src/plugins/host.rs` 的错误走 `plugins::text("plugin.error.…")`，翻译在 `locales/` 里；没有引擎（crate 单测）时返回 key 本身，`t!` 不会 panic。
6. **测试固定语言。** `App.test.tsx` 用 `open(..., { locale: "zh-CN" })` 断言中文；另有一条用例切到 `English` 再切回中文，覆盖 `setLocale` 与选择器。

## 测试夹具的 `locales/`

`test-fixtures/` 有自己的 `nsh.json`（`capabilities.host` 含 `cursor.*`、`plugins.*`、`calls.*`），因此 `nsh test` 从 `test-fixtures/locales/` 读翻译。该目录是指向 `../locales` 的符号链接，避免文案抄两份。

## 与上游 cursor-byok 的差异

| 上游（`jsProject/cursor-byok/apps/desktop`） | 本仓库 | 原因 |
|---|---|---|
| 自建 `src/i18n/`（`runtime.ts`、`store.ts`、`I18nRoot.tsx`、`generated/catalog.json`、`i18n:scan` 脚本） | NSH 的 `nsh/i18n` + `locales/*.yml` | 框架内置：翻译打包、热更新、语言回退、`Intl` 数据都由 nsh 完成，不需要自建运行时和扫描脚本 |
| 语言偏好存 settings store | `Storage` 键 `cursor-byok-next:locale` | 语言只有“系统 / 具体语言”一个值，键值存储足够，不需要进 Rust 侧的设置存储 |
| `en-US` / `pt-BR` / `zh-CN` | `zh-CN` / `en-US` | 目前只维护这两种；新增语言 = 加 `locales/<tag>.yml` + `nsh.json` 的 `locales` + `Language.tsx` 的 `NAMES` |
| 语言入口在设置页 | 只在系统设置页（侧栏底部不再放选择器） | 入口收在一处：侧栏底部只留导航，避免同一个设置出现两份镜像 |
